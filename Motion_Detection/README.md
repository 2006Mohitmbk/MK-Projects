# Real-Time Motion Detection System

This project uses OpenCV and a webcam to detect movement in real time.

## How it works

Webcam
↓
Capture Frame
↓
Convert to Grayscale
↓
Blur Image
↓
Compare Frames
↓
Detect Difference
↓
Find Moving Areas
↓
Draw Rectangle
↓
Display Result

## Requirements

- Python
- OpenCV
- Webcam
